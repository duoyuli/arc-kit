# 代码锚点协议

锚点把 arc-kit 的手写语义入口连接到工程文档中的稳定章节。只有阅读代码确实需要非局部知识时才添加；不以数量作为覆盖标准。

## 语法与目标

```text
@project-doc docs/<path>.md#<section_id>
```

- 标记固定为小写 `@project-doc`，一行一个目标。
- 路径从仓库根开始，指向已在 `docs/index.md` 或分类目录中登记的 Markdown 正文；不使用绝对路径、`../` 或远程 URL。
- 文档文件与目录遵循文档库的小写 `snake_case` 规则，章节 ID 为 `[a-z][a-z0-9_]*`。
- 目标章节在标题前声明 `<a id="section_id"></a>`；同一文档内 ID 唯一，不依赖渲染器根据标题生成的 slug。

普通文档链接相对所在文件解析，可以使用标题 slug；它与此处的代码锚点不是同一套路径或 ID 规则。

## Rust 与配置示例

以下为格式示例，所示 `docs/` 文件并非当前已有文件。先建立并登记真实目标章节，再把锚点放入源码。

```rust
// 安装目标的归属校验与台账范围共同决定是否允许清理。
// @project-doc docs/domains/skill_installation.md#ownership_check
fn inspect_installation_owner() {
    // 此处仅演示锚点与中文说明的位置。
}
```

对应章节：

```markdown
<a id="ownership_check"></a>
## 安装目标归属

说明目标路径、来源、安装策略与台账证据如何共同确定归属。
```

Rust 使用 `//`，TOML 和 YAML 使用 `#`，Markdown 使用 `<!-- ... -->`。锚点标记本身是机器协议，解释性注释另行使用中文，遵从 `AGENTS.md`。保留既有 Rust 文档注释的作用，不用锚点替代必要的 API 说明。

JSON 不能包含注释；持久化 JSON 契约应锚定到 Rust 的模型、加载器或校验入口。生成文件、锁文件和 vendored 代码也选择其手写来源，不直接插入标记。

## 放置位置

优先选择真正拥有语义的入口或类型：

| 需要连接的工程知识 | 在当前仓库中寻找入口 |
| --- | --- |
| 项目声明对齐、接管、agent 范围与清理 | `arc-core/src/project/skills.rs` 的协调入口，必要时关联 `arc-core/src/project/apply.rs` |
| 安装归属、台账迁移和事务恢复 | `arc-core/src/skill/install/` 中相应类型、校验和事务入口 |
| CLI 的交互选择或 JSON 契约 | `arc-cli/src/commands/common.rs`、`arc-cli/src/format.rs` 或具体命令边界 |
| Provider 原生配置与登录态切换 | `arc-core/src/provider/` 中负责映射、写入或恢复的入口 |

锚点跟随语义所有者，放在符号或配置块附近，不统一堆在文件头，也不在所有调用方重复粘贴。测试只有在自身定义跨模块契约、且没有合适生产入口时才需要锚点。普通 README 导航继续使用普通链接，不要求为每个用户说明建立代码锚点。

## 读取与维护

在解释、审查或修改锚点所属语义单元前，读取目标章节，并补读理解它需要的范围说明和直接依赖。目标失效是文档漂移：只读任务报告位置；允许修改的任务先核实真实归属，再修复目标、锚点或两者。

- 改标题但语义不变：保留 ID。
- 移动代码：锚点跟随语义所有者。
- 移动文档：保留语义 ID，同步代码中的仓库相对路径、各级目录与普通链接。
- 拆分或替换语义：逐个判断旧入口需要哪个新章节，必要时创建新 ID；不要凭标题相似直接改指。
- 删除功能：先迁移仍有效的知识，再清理相应锚点、章节与目录。

文档库尚未建立时，保留清楚的中文代码注释，不创建指向计划文件的锚点。技能参考及模板中的示例标记不算实际源码锚点。

## 检查

在仓库根枚举实际源码锚点：

```sh
rg -n '@project-doc' arc-core arc-cli arc-tui built-in
```

有其他手写配置文件或新增模块时扩展搜索路径。对每个实际锚点检查目标文件、目录归属、完全匹配的显式 ID，以及附近符号是否仍拥有该语义。再从变动章节反向搜索入口引用，确认移动或拆分后没有漏改。

示例中的占位路径单独识别，不作为失效的生产锚点计数。只有目标文件存在并不代表锚点正确，还需核对目标内容与入口语义。
