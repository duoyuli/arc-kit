## Why this project qualifies

```text
arc-kit is an open-source Rust CLI for developers who use multiple coding agents such as Codex, Claude Code, Cursor CLI, OpenCode, Gemini CLI, Kimi CLI, and others. It provides one consistent way to manage provider profiles, reusable skills, shared skill markets, and project-level agent configuration. The project targets a growing maintenance problem in the agent tooling ecosystem: every agent has different config paths and skill conventions, making setup, upgrades, and team collaboration fragile. arc-kit is publicly released, installable via Homebrew, and actively maintained.
```

## How I would use API credits

```text
I would use OpenAI API credits to improve arc-kit’s development and maintenance workflow: testing Codex-oriented provider integration, generating and validating cross-agent configuration examples, reviewing pull requests, triaging issues, improving documentation, and building regression checks for skill installation and project configuration behavior. The credits would help make arc-kit more reliable for open-source maintainers who depend on multiple coding agents in real projects.
```
